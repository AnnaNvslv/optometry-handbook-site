# Оптометрия по Ринской

Закрытое учебное приложение по «Настольной книге оптометриста» (Н. В. Ринская, 2018). Только для личного обучения.

- `content/` — опубликованные уроки (по шагам)
- `src/` — оболочка: алгоритм, схемы, стили, страница входа
- `build.js` — собирает `dist/app.html` и шифрует его в `dist/index.html` (AES-GCM, пароль из секрета `SITE_PASSWORD`)
- GitHub Action публикует зашифрованный файл в публичный репозиторий `optometry-handbook-site` (секрет `SITE_TOKEN`)
